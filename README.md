# CSS Components Showcase

A premium-looking collection of clean, responsive, and reusable CSS-only components designed for modern UI development.

## 🚀 Project Overview

The **CSS Components Showcase** is a lightweight, zero-dependency library of interactive user interface elements. Built with pure HTML5 and CSS3, it offers developers a reference layout and copyable snippets to implement high-quality visual components in any web project without framework overhead.

## 🛠️ Technologies Used

*   **HTML5**: Semantic elements and responsive structure.
*   **CSS3**: CSS Custom Variables, CSS Grid, Flexbox layouts, dynamic animations, backdrop filters, and custom transitions.
*   **Vanilla JavaScript**: Extremely lightweight clipboard copy interactions and scroll state tracking.

## 📂 Folder Structure

```text
/
├── index.html       # The main interface, navigation layout, component structures, and code viewers.
├── style.css        # The complete styling system, theme colors, responsive grids, and components.
└── README.md        # Documentation, running instructions, and future roadmap.
```

## 🎨 Design System Overview

The showcase uses a human-designed, sleek dark slate theme inspired by professional design systems (Tailwind UI, Stripe, Linear):
*   **Backgrounds**: Deep slate background (`#0b0f17`), card surface containers (`#111827`), elevated control surfaces (`#1f2937`), and inset preview panes (`#090d16`).
*   **Typography**: *Inter* and *Outfit* for modern sans-serif typography with tight letter spacing (`-0.02em`) and balanced hierarchy; *Fira Code* for monospace code snippets.
*   **Accents**: Indigo (`#6366f1` / `#4f46e5`) for main CTAs, violet (`#8b5cf6`), slate cyan (`#06b6d4`), emerald green (`#10b981`), and amber (`#f59e0b`).
*   **Borders & Shadows**: Crisp 1px borders (`rgba(255, 255, 255, 0.08)`), realistic subtle drop shadows, and clean focus rings.

## 🛠️ Component Breakdown (Version 2.0 - 35+ Components)

### 1. Buttons (12 Unique Variants)
*   **Primary Button**: Standard CTA button with hover elevation and shadow expansion.
*   **Secondary Button**: Muted card-toned border button with hover scaling.
*   **Outline Button**: Clean stroke-based button that transitions to a solid background fill.
*   **Gradient Button**: Dual-color backplate with moving background position on hover.
*   **Neon Glow Button**: Intense cyan glow shadow that scales and illuminates on mouse-over.
*   **Sliding Fill Button**: Button using pseudo-elements to slide a background overlay block from left to right.
*   **Glass Liquid Button**: Semi-transparent frosted glass container with glowing border sweep.
*   **Shimmer Sweep Button**: Dark metallic sheen with rotating diagonal light sweep on hover.
*   **Cyberpunk Sci-Fi Button**: Clipped-polygon angular neon button with high-voltage cyan glow.
*   **Neumorphic Soft Button**: Soft extruded & pressed 3D dark shadow interaction.
*   **Magnetic Conic Pill Button**: Rounded full pill with rotating conic-gradient halo.
*   **Tooltip Action Button**: Icon button with a floating micro-tooltip drawer on hover.

### 2. Cards (9 Unique Variants)
*   **Simple Card**: Classic box element with rounded borders and hover translation (lift).
*   **Glassmorphism Card**: Semi-transparent border card using backdrop blur filters.
*   **Gradient Border Card**: Card with continuous linear gradient borders using overlay techniques.
*   **3D Perspective Tilt Card**: Interactive card with 3D transform rotation and spatial elevation shadow.
*   **Pricing Plan Tier Card**: Subscription tier card with price tag, feature list, and popular ribbon badge.

*   **Glowing Aura Feature Card**: Radial glow background aura expanding on hover.
*   **Interactive 3D Flip Card**: Double-sided 180° flip reveal card using `preserve-3d`.

### 3. Inputs (9 Unique Variants)
*   **Minimal Input**: Inline bottom border input featuring label float adjustments.
*   **Floating Label Input**: Floating text input that shifts size and alignment on focus.
*   **Glowing Focus Input**: Standard field transitioning to an intense indigo focus box-shadow.

*   **Dual Icon Verified Input**: Input box with leading mail icon and trailing emerald checkmark.

*   **Pulse Loader**: Twin expanding pulse rings that fade in opacity.

*   **Segmented Progress Bar**: Multi-block progress track with glowing active pulse sequence.
*   **Terminal Cursor Loader**: CLI command shell with blinking emerald prompt cursor.
*   **DNA Helix Wave Particles**: Oscillating vertical bars creating a 3D helix wave motion.

## ⚡ Interactive Features
